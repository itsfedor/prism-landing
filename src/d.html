Questions

Fair questions,
straight answers.

What does it cost, and what do I need to run it?
Nothing, and not much. The suite is MIT licensed with no paid tier. You need Node 18+ and Python 3.9+ on Linux or macOS, plus an AI agent that reads SKILL.md files.
Is my Edvibe password safe?
You type it yourself, once, in your own terminal, and it is never stored. The session token stays in a file on your machine, and the CLI talks to Edvibe from your computer — not through anyone's server.
Will it break when Edvibe changes?
It can. The CLI talks to an undocumented API surface, so an Edvibe update may break it. The skill documents the recovery steps, and the code is open, so fixes land in the repo.
Do I need prompt engineering skills?
No. You describe the lesson in plain words, like “Present Perfect for a 7th grader,” and the skill carries the structure. Read the output the way you would read any draft.
Which agent do I need?
Any agent that reads agentskills.io SKILL.md files: Hermes Agent, Claude Code, Codex CLI, Cursor, and 70+ more. The default install targets every detected agent; add a flag to pick one.
Can I use it with students at any level?
From A1 through C1. Exercises are written for one student from their level, interests and weak spots, and the level never goes up without you asking.
